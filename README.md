Leonida Trophy Guide — an offline GTA 6 trophy guide and tracker for all 55 official trophies, with sourced guides, a platinum roadmap, missable flags, a saved checklist with export and import, filters, and a spoiler mode.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
